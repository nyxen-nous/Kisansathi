# AZINHACK submission assets

This folder is the working submission kit for the KisanSaathi project.

- `KisanSaathi_AZINHACK_Pitch_Deck.pptx` — 9-slide pitch deck. Review team name/details and any event-specific requirements before uploading.
- `DEMO_RUNBOOK.md` — setup and timed walkthrough for the required 2–3 minute demo video.
- `JUDGE_WALKTHROUGH.md` — short pitch and technical Q&A notes.
- `SOCIAL_POST_DRAFT.md` — post copy; insert the actual public repository and demo URLs before publishing.
- `RUBRIC_READINESS_CHECKLIST.md` — evidence gate aligned to the scoring rubric.
- `TEAM_CONTRIBUTIONS_WORKSHEET.md` — complete with real names and evidence; do not publish it unchanged.

No TinyFish API key is packaged. A real live request must be verified on the demo machine before recording the final video.
